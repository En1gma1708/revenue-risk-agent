Add multi-agent PoC, live demo features, and dashboard pages

Backend:
- Add backend/pydantic_agents.py: router -> 3 surface-specialist multi-agent
  architecture on Pydantic AI, sharing the same guardrails.py enforcement as
  agent_loop.py (no duplicated compliance logic). Verified live on 2/3
  surfaces.
- Add backend/orchestrator.py and backend/execution_handoff.py: earlier
  hand-built multi-agent PoCs exploring narrower handoff shapes, kept as
  evidence of the exploration.
- Add backend/tests/test_pydantic_agents.py: 26 tests covering all 8 shared
  tools, status finalization, RoutingDecision validation, and a guardrail
  parity test proving agent_loop.py and pydantic_agents.py enforce policy
  identically. Full suite: 58/58 passing.
- Add backend/custom_case.py: live single-case submission through the real
  agent loop, backing the dashboard's /try page.
- Add backend/bulk_upload.py: CSV/XLSX bulk upload (15-row cap) with a
  downloadable sample workbook.
- Add backend/stress_test.py: proves the deterministic pipeline (routing,
  guardrails, persistence, metrics) scales to 1,000+ cases.
- backend/run_batch.py: default --providers changed from
  gemini,groq,openrouter to groq,openrouter (Gemini measured at ~2.5% clean
  conversion vs Groq/OpenRouter, deprioritized not removed).

  groq.
- backend/generate_cases.py: add CLI args (--n-payment/--n-checkout/
  --n-receivable/--out-dir/--seed); fix a days_overdue < 3 edge case found
  via stress_test.py.
- backend/app.py: wire up new /try and bulk-upload endpoints.
- backend/requirements.txt: add pydantic-ai-slim[groq,openai], openpyxl,
